# Quotes Scraper

Скрапер на базе Playwright, который собирает цитаты с `quotes.toscrape.com/scroll` и сохраняет их в `out/result.json`.

## Локальная разработка
1. Убедитесь, что у вас установлен Docker и Make.
2. Выполните `make build` для сборки образа.
3. Выполните `make run` для запуска и генерации `out/result.json`.

## Сборка продакшн-образа
Используется многоступенчатый Dockerfile на базе `node:22-bookworm`. 
Команда `make build` создает оптимизированный образ, использующий кэш BuildKit для системных зависимостей, npm-пакетов и бинарных файлов браузера, что гарантирует быструю пересборку при изменении кода.
