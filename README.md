# Quotes Scraper

Скрапер на базе Playwright, который собирает цитаты с `quotes.toscrape.com/scroll` в Chromium. Во второй лабораторной работе результаты сохраняются в облачную инфраструктуру (S3 и SQS), развёрнутую локально в `floci/floci:2.2.0` и описанную через Terraform.

## Архитектура
* `src/index.js` — ядро скрапера на Playwright (собирает цитаты и записывает в `out/result.json`).
* `src/worker.js` — инфраструктурная обёртка: получает задание из очереди SQS, запускает `src/index.js`, загружает готовый JSON в S3 bucket и удаляет сообщение из очереди только после успешной записи.
* `src/send-task.js` — скрипт отправки задания в SQS и проверки результата в S3.
* `infra/` — конфигурация Terraform для создания S3 bucket и SQS queue.

## Локальная разработка и требования
Убедитесь, что у вас установлены:
* Docker и Docker Compose
* Terraform (`>= 1.5`)
* Make

## Управление окружением и запуск (Makefile)

Все операции выполняются исключительно через `Makefile`:

* **`make provision`** — запускает локальное облако Floci (`floci/floci:2.2.0`) в Docker, инициализирует Terraform и создаёт S3 bucket (`quotes-bucket-local`) и SQS queue (`quotes-tasks-queue`). Повторный запуск идемпотентен и не изменяет существующую инфраструктуру.
* **`make deploy`** — собирает Docker-образ приложения и запускает фоновый контейнер воркера (`quotes-worker`), передавая параметры подключения к S3 и SQS через переменные окружения.
* **`make run`** — отправляет одно задание в очередь SQS, ожидает завершения скрапинга, проверяет наличие непустого валидного JSON в S3 и убеждается, что обработанное сообщение удалено из очереди.
* **`make destroy`** — останавливает воркер, удаляет ресурсы через `terraform destroy` и останавливает контейнер Floci. Повторный запуск безопасен и завершается без ошибок.
* **`make build`** — собирает Docker-образ скрапера.
* **`make clean`** — удаляет Docker-образ, контейнер воркера и локальную директорию `out/`.
* **`make ci`** — проверяет форматирование (`terraform fmt -check`), инициализирует провайдеры без бэкенда, валидирует конфигурацию (`terraform validate`) и строит план (`terraform plan`).

## Сборка продакшн-образа
Используется многоступенчатый Dockerfile на базе `node:22-bookworm`. 
Команда `make build` создает оптимизированный образ, использующий кэш слоёв Docker для системных зависимостей, npm-пакетов и бинарных файлов браузера Chromium, что гарантирует быструю пересборку при изменении исходного кода.
